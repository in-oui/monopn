# monopn

[English](README.en.md) | 日本語

`monopn` は、BSD Games の `monop` をベースにした端末用ボードゲームです。
元のゲーム内容を保ちつつ、現在の環境でゲーム状態を安全にセーブ／ロード
できるように改修しています。

これは非公式のオープンソースプロジェクトです。

## 主な変更点

- プロセスのメモリを直接書き出す旧セーブ方式を廃止
- バージョン付きのポータブルなセーブ形式を採用
- プレイヤー、所持金、位置、物件、抵当、家、カード山などを復元
- 破損または互換性のないセーブファイルを検出
- Linuxでビルドできるように互換性を追加

新形式導入前の `monop` で作成されたセーブファイルとは互換性がありません。

## 必要環境

- Linux（現在の配布バイナリは x86-64 用）
- Cコンパイラ（GCCまたはClang）
- GNU Make

## ビルド

リポジトリのディレクトリで次を実行します。

```sh
make
```

次のファイルが生成されます。

- `monopn`: ゲーム本体
- `cards.pck`: ChanceおよびCommunity Chestのカードデータ

生成物を削除する場合は次を実行します。

```sh
make clean
```

## 実行

`monopn` は同じディレクトリにある `cards.pck` を読み込みます。

```sh
./monopn
```

既存のセーブファイルから開始する場合:

```sh
./monopn path/to/saved-game
```

ゲーム中は `-- Command:` にコマンドを入力します。主なコマンドは次の通りです。

| コマンド | 内容 |
| --- | --- |
| `roll` または空行 | サイコロを振る |
| `print` | 盤面を表示する |
| `where` | プレイヤーの位置を表示する |
| `own holdings` | 自分の所持内容を表示する |
| `holdings` | 指定したプレイヤーの所持内容を表示する |
| `mortgage` / `unmortgage` | 物件を抵当に入れる／戻す |
| `buy houses` / `sell houses` | 家を購入／売却する |
| `trade` | 他のプレイヤーと取引する |
| `save` / `restore` | ゲームを保存／復元する |
| `quit` | ゲームを終了する |

文字列の選択肢を聞かれたときに `?` を入力すると、有効な回答を確認できます。

## 配布

実行ファイルを配布するときは、必ず `cards.pck` と一緒にしてください。

```sh
tar czf monopn-linux-x86_64.tar.gz monopn cards.pck
```
